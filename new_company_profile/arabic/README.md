# النسخة العربية من ملف نست

ملف PDF مستقل من 15 صفحة، مع مصدر HTML قابل للتحرير وتنسيق من اليمين إلى اليسار. يستخدم الصور والشعارات في مجلد assets المشترك؛ يجب الحفاظ على ترتيب المجلدات عند نقل مصدر HTML. أسماء العلامات التجارية وبيانات الاتصال محفوظة بلغتها الأصلية.

إعادة الإنشاء: اضبط PLAYWRIGHT_PATH ثم شغّل node ../build-arabic.cjs.
